365 projetos para codar um por dia
Um projeto pequeno e concluível por dia. Desafios progressivos, com escopo mínimo. A linguagem sugerida pode ser trocada.

Regra do desafio: escreva o código sozinho; use documentação para pesquisar; teste pelo menos um caso normal e um caso de erro; faça um commit ao concluir.
